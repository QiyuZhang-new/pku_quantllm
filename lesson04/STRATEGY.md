# 策略说明书：A 股短期反转 + 趋势过滤

> 面向 `lesson04` 的 7 个 Feather 日频矩阵（2020-01-02 至 2026-10-16）。
> 本文档是**策略规格**，供实现方（codex）按此开发；参数均为可调变量，默认值是起点而非最优。

## 0. 一句话

在**市场处于长期上升趋势**时，买入**近 5 日跌幅最深的、流动性最好的一篮子股票**，等权持有若干天后卖出，赚取**短期反转**的钱。

## 1. 设计依据（为什么是这些规则）

| 设计选择 | 原因 |
| --- | --- |
| 用"过去 N 日收益率排序"而非 RSI(14) | RSI(14)<30 主要是**下跌趋势的症状**，不是反弹信号。短期反转效应（1–5 日）在 A 股比美股更显著，直接用收益率排序比 RSI 这个粗糙代理更接近机制本身。 |
| 横截面一篮子（10–30 只），而非单标的择时 | 反转因子的收益来自**横截面排序**；押注单只等于承担个股爆雷风险，且指数时序择时扣成本后通常打不过买入持有。 |
| 加 MA200 regime 过滤 | 顺大势、逆小势。过滤掉系统性下跌期里"越跌越买"的连续亏损段。 |
| 固定持有 5 日而非 1–2 日 | **T+1** 掐掉了最短的信号；把持有期拉到 3–10 天，T+1 从硬伤变成无关约束。 |
| 成交额做**流动性**筛选（不用"大盘"） | 数据里**没有市值/行业/指数成分**，只能拿成交额当代理。 |

> ⚠️ 数据里同样**没有指数**。所谓"市场 regime"需自行用全市场等权或成交额加权合成一个代理指数，并明确说明这是近似。

## 2. 规则明细

### 2.1 股票池（每日重算）
- 取当日**成交额排名前 N** 的股票（默认 `N = 500`）作为基础池。
- 剔除：当日停牌、当日成交额为 0 或缺失、上市不足 `MIN_LISTED = 60` 个交易日的股票。
- 若可得，剔除 ST / 退市整理股（**本数据集不含该字段，如无则明确记录这一缺口**）。

### 2.2 信号
```
signal_i(t) = close_adj_i(t) / close_adj_i(t-5) - 1        # 5 日复权收益率
close_adj_i(t) = close_i(t) × cumadj_i(t)                  # 复权口径见 §5.3
```
- 在股票池内**升序排序**，取最跌的 `K` 只（默认 `K = 20`）。
- 备选对照信号：`RSI(2) < 10`（Connors 风格），用于检验收益率排序是否真的优于 RSI。

### 2.3 Regime 过滤
- 合成市场代理指数 `M(t)`：全市场等权日收益累乘（或用成交额加权）。
- 仅当 `M(t) > MA200(M, t)` 时**允许开仓**；不满足时保持空仓（或只持有既有仓位至到期，二选一，需在报告中写明）。
- 注：MA200 需要约 200 个交易日预热，前 200 天不产生信号。

### 2.4 组合与持有
- 等权买入 `K` 只，单只权重 `1/K`。
- **固定持有 `H = 5` 个交易日**后卖出（默认）。
- 为避免同一天集中成交，可把建仓日错开为 `H` 个子组合（tranched），使每日都有 1/H 的仓位换手——这能降低冲击成本、也让净值更平滑。**默认可先不做，作为第二阶段优化。**

### 2.5 执行与成交价（决定回测真假的地方）
- 信号在 `t` 日**收盘后**生成，`t+1` 日**开盘**成交（绝不允许用 `t` 日收盘价"买入"）。
- **跌停不能买**：若 `t+1` 开盘价 ≤ 前收 ×(1−跌停幅度)，或当日 `open == high == low` 且为跌停价，则视为**无法成交**，跳过该标的（不补其他标的，也不延迟）。
- **涨停不能卖**：卖出日同理处理。
- 停牌日不可交易，顺延至下一个可交易日，并在报告中统计被顺延的比例。

### 2.6 成本
- 单边成本默认 **0.15%**（佣金 + 过户费 + 滑点），卖出额外加**印花税**。
- 印花税在样本期内**变过**：2023-08-28 之前为 0.1%，之后为 0.05%。回测应按时点分别建模，不要用单一常数。
- 双边合计约 **0.3%–0.45%**，实现时以参数形式暴露，便于做成本敏感性测试。

## 3. 基准

必须至少对比以下三个，否则"赚钱"无法定义：

1. **买入持有**市场代理指数 `M(t)`。
2. **等权全市场**（同股票池，不做信号）。
3. **无 regime 过滤**的同信号版本（用来看过滤到底贡献了多少）。

## 4. 先体检，再开发

**建议在 codex 动手写系统之前，先花几分钟做信号体检**（纯分析脚本，非回测系统）：

1. 超跌组在信号后 **1 / 3 / 5 / 10 / 20 日**的平均收益，与股票池均值相减得**超额收益**。
2. 该超额收益**是否大于双边成本**（约 0.3%–0.45%）。若 5 日超额收益显著低于成本，方向直接放弃。
3. 信号股票中**因跌停无法买入的比例**。
4. 分年度看超额收益是否稳定（2020–2026 跨越了多种市场状态）。
5. 对照 `RSI(2)<10` 与"5 日收益率最低"两种排序，看哪种超额更高。

体检结论决定是否值得投入开发。**这一步的成本远低于写完整回测系统。**

## 5. 关键陷阱

### 5.1 未来函数
- 信号只能用 `t` 日及之前的数据；`t+1` 开盘成交。任何用到 `t+1` 信息的写法都会让回测虚高。

### 5.2 幸存者偏差
- 矩阵是**当前仍在的 5,451 只**证券构成的历史面板。已退市股票大概率不在其中，会让历史收益**偏乐观**。需在报告中明确记录这一缺口。

### 5.3 复权口径（已实测验证 ✅）

**结论：`复权价 = close × cumadj`（乘法），不是除法。**

验证方法与结果（2026-10-16 实测）：

- 全样本共 **25,736 个除权日观测**（`|cumadj 日变动| > 0.1%` 的日子）；每只股票中位数约 **5 次**复权事件，符合年度分红派息的量级。
- 在**除权日**上统计平均绝对日收益（越小越连续）：

  | 序列 | 除权日 mean \|日收益\| |
  | --- | ---: |
  | 原始 `close` | 0.05829 |
  | **`close × cumadj`** | **0.02070** ✅ |
  | `close ÷ cumadj` | 0.09211 |

- 对照组：在**非除权日**上，原始 `close` 与 `close × cumadj` 的平均绝对收益**完全相同（均为 0.02175）**——因为 `cumadj` 在这些日子恒定。这证明上述掩码正确，且乘法确实把除权日的跳变**抹平到了正常交易日的水平**。

补充注意：

- `cumadj` 的量级约 **98–127**（并非从 1 开始），属前复权/后复权某种累计因子；**它只用于算收益率，不能当作真实价格**。
- **涨跌停判定必须用原始 `close`/`open`**，不能用复权价（复权价的绝对水平无意义）。
- 用未复权价算收益率会在除权日产生**假暴跌**，把除权股误判为"超跌"，系统性污染信号——这正是必须乘 `cumadj` 的原因。

### 5.4 T+1
- 买入当日不可卖。若持有期 `H = 1`，实际最小持有是 2 日。规格已用 `H = 5` 规避。

### 5.5 缺失值
- 各矩阵约 **12.5% NaN**，对应停牌/未上市区间。不可 `fillna(0)`，也不可前向填充后当作可交易。

## 6. 参数汇总

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `N`（成交额前多少名） | 500 | 流动性池大小 |
| `K`（持有只数） | 20 | 越多越稳，但越接近市场平均 |
| `L`（回看天数） | 5 | 反转信号窗口 |
| `H`（持有天数） | 5 | 规避 T+1 |
| `MA`（趋势均线） | 200 | regime 过滤 |
| `MIN_LISTED` | 60 | 上市天数下限 |
| 单边成本 | 0.15% | 不含印花税 |
| 印花税 | 0.1% / 0.05% | 2023-08-28 切换 |

## 7. 失败判据（先写下来，避免事后找理由）

出现以下任一情况，判定该方向不成立，不追加投入：

- 5 日超额收益（扣成本后）≤ 0；
- 超额收益仅由 1–2 个年份贡献，其余年份为负；
- 信号股票中因跌停无法成交的比例过高（如 > 20%），导致可执行样本的收益与理论值严重不符；
- 加入合理滑点后净值曲线不显著优于"等权全市场"基准。

本策略仅为课程实践与研究用途，**不构成任何投资建议**。回测结果不能证明策略在真实市场可盈利：数据缺失、幸存者偏差、涨跌停不可成交、冲击成本等均会使实盘表现差于回测。
