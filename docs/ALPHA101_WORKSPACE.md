## Alpha101接入范围

原始来源为 Zura Kakushadze，[101 Formulaic Alphas，arXiv:1601.00991v3](https://arxiv.org/abs/1601.00991v3)，附录A。
Alpha101为101个公式的集合；Alpha#101是其中一个。

当前实现编号：4、9、10、18、20、23、33、101，共8个。界面提供全部101个编号的状态目录，
未实现编号不能被提案器执行。原文含delay-0公式，不能直接视为次日开盘可执行策略。

输入与计算约定：

- 价格为原始OHLC乘当日累计复权因子，不用全样本末值归一化。
- 横截面rank为当日历史eligible掩码内的平均百分位秩；时序秩同样采用平均百分位秩。
- 滚动窗口要求完整观测；std采用样本标准差，除法无效值保留缺失。
- Alpha#101保留原文分母中的0.001常数，因此价格单位与复权约定属于研究定义的一部分。
- 信号收盘后形成，次日开盘进入，沿用既有标签、历史状态、容量与费用验证。
- 本地没有真实volume、VWAP、行业及市值字段；不使用amt或num_trades替代volume。
- 这是公开公式在当前数据与执行协议下的研究实现，不是原论文专有市场实验的复现。

实现文件为 `quant_research/alpha101.py`，表达式例子：

```json
{"name":"alpha101","expression":{"op":"alpha101","number":101},"hypothesis":"检验日内动量相对振幅"}
```

变体仍由本地规则反馈生成，包括平滑及与另一个明确Alpha公式的秩组合；不执行任意Python。
算子版本升级为 `causal-price-volume-v2-alpha101`，避免将旧算子ID与新版本混用。

## 新研究操作

1. 在页面展开“新建演化研究”，选择真实行情或合成对照、固定120股或完整面板、资金与种子。
2. 设置轮数和每轮预算，点击开始。任务参数先保存，后台进程单独执行，界面可继续查询。
3. 使用“打开研究”进入记录，拖动回放滑块，只看相应轮次之前已出现的候选。
4. 查看演化驾驶舱的多指标表及父子公式对比，再进入候选页查看账户与准入明细。
5. 停止请求在轮次边界检查；当前轮可能继续计算。停止、异常和中断不算研究成功。

网页后台只执行开发搜索，合成模式也不自动审核。完整面板会明显增加CPU、内存和磁盘开销。
进程锁只覆盖网页研究任务，不代表与所有手动CLI操作共用全局资源锁。
当前版本仍无LLM在线调用、组合边际贡献、前瞻模拟交易或自动退役。
