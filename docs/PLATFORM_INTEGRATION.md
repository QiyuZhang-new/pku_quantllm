# 因子演化接入原量化交易系统

产品展示名称统一为 **ALPHA GENESIS · 阿尔法创世**，策略回测、因子演化为功能模块名。

日期：2026-11-06。

## 统一入口

唯一主入口为 `lesson04/app.py`，侧栏“策略回测 / 因子演化”。沿用原本机端口8501。
原回测配置、行情缓存、策略运行、历史结果及ZIP导出继续使用原模块。
演化页面抽取为 `research_ui/app.py` 的组件；`research_app.py`仅作旧启动命令兼容，
它同样加载主入口，默认选中因子演化，不再维护独立网页。

## 数据与任务配置

- 原 `QUANTLLM_DATA_DIR` 同时供回测与真实行情演化任务使用。
- `QUANTLLM_STATUS_DIR` 可指定与该行情匹配的逐证券状态目录。
- 原课程默认行情使用既有历史状态缓存；自定义行情未指定状态目录时，
  不擅自混用课程缓存，可以由行情宽表提供状态，缺失则按原协议拒绝准入。
- 原 `QUANTLLM_RUNS_DIR` 保存原生回测及导入实验，`QUANTLLM_RESEARCH_RUNS_DIR` 保存研究证据。
  两种格式各自保留，通过同一页面工作流和来源标识连接。
- 网页任务请求保存实际行情与状态路径，后台进程使用该配置；预算、费用与研究时间仍随新批次冻结。

## 从研究候选进入原回测视图

在因子演化中选择候选与已完成窗口，点击“在策略回测中打开此结果”。

1. 读取该窗口已有账户净值、成交、持仓、拒单和费用，不重新运行策略。
2. 按原回测产物格式保存到回测历史目录，生成原生参数、绩效、图表及experiment.json。
3. 来源包含批次、因子ID、窗口、开发/审核结论、是否通过账户门槛及文件SHA-256。
4. 同一来源重复导入使用同一实验目录，拒绝覆盖来源不一致的已有目录。
5. 在同一Streamlit会话切换回“策略回测”，使用原有明细、历史浏览和ZIP下载。

开发拒绝的候选可以作为研究对照导入，顶部明确显示拒绝状态，始终标记research_only。
这不等于策略晋升、前瞻验证或允许实盘交易。尚未完成的候选不能导入，历史审核未结束时也不能导入审核窗口。
导入过程检查源文件变化、使用进程锁和临时目录原子落盘，不修改源研究产物。
