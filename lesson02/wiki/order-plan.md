# 价格触发下单方案（待确认后接入实际发单）

题目明确要求先给方案、确认后执行。本次没有调用 `reqOrderInsert`，也没有开平仓成交证据；老师 10 月 7 日补交标准中的实盘仿真闭环仍待后续验收。

1. 仅允许 SimNow、一个合约、一手。启动查询持仓及活动委托；若已有持仓/活动委托或状态不明则停止。默认 dry-run。
2. TD 链：连接 → `reqAuthenticate` → `reqUserLogin` → 结算确认 → 查询合约、持仓、账户。校验最小跳价、合约交易状态、保证金与价格边界后才允许触发。
3. 行情超过阈值只生成一次开仓意图，使用 SQLite 唯一键 `(trading_day, strategy, symbol)` 并在发单前提交事务。重启先对账，不能自动重发未知订单。
4. 开多限价按 ask1 及 pricetick 取整；最多一手。归属匹配 `FrontID + SessionID + OrderRef`，取得 `ExchangeID + OrderSysID` 后核对成交；成交按 `ExchangeID + TradeID` 去重。
5. 只在明确开仓成交后生成平仓意图。SHFE/INE 区分平今和平昨，使用实际成交量，不能用“订单发出”代替“成交”。
6. 超时/断线/拒单进入失败状态，禁止新增风险；已知活动委托可以撤单并等回报。状态未知时退出码非零并要求人工对账，不能宣称已空仓。
7. 验收必须同时有平仓成交回报、柜台持仓查询完成且目标持仓为 0、完整活动委托查询完成且为空。脱敏日志只保留本策略必要字段，不输出凭据或完整资金快照。

不采用自动反复补单：不确定状态下重发可能造成双倍持仓。行情订阅与下单权限应独立开启。
